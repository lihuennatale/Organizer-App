# Organizer App

**Organizer App** is an interactive desktop application developed in **Python** using the **Pygame** library. This project simulates a productivity tool designed to help users manage their daily activities, notes, and tasks within a sleek, custom-built graphical user interface (GUI).

## Key Features

* **Task Management:** A dedicated space to list and organize your daily to-dos.
* **Quick Notes:** An integrated section to capture ideas, thoughts, or reminders on the fly.
* **Modern GUI:** A clean interface designed with a professional color palette (Dark Gray/Minimalist) built from scratch using `pygame`.
* **Interactive Navigation:** Smooth handling of mouse and keyboard events for a dynamic user experience.

##  Tech Stack

* **Language:** [Python 3.x](https://www.python.org/)
* **Graphics Library:** [Pygame](https://www.pygame.org/)
* **Environment:** Jupyter Notebook (`.ipynb`)

## Getting Started

Follow these steps to run the application on your local machine:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/lihuennatale/Organizer-App.git](https://github.com/lihuennatale/Organizer-App.git)
    cd Organizer-App
    ```

2.  **Install dependencies:**
    Make sure you have `pygame` installed:
    ```bash
    pip install pygame
    ```

3.  **Run the application:**
    Open `Organizer App.ipynb` in your preferred environment (VS Code, Jupyter Lab, or Jupyter Notebook) and run all cells to launch the application window.

##  Project Structure
